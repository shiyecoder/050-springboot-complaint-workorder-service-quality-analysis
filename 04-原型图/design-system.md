# 客诉工单与服务质量分析系统 · 设计系统

> 视觉方向：**数据钢蓝**的专业业务系统风格。以数据可读性、操作效率、状态辨识为第一目标，不使用巨幅英文口号、装饰性光效、悬浮球、过度渐变或大面积插画。整体观感接近单位内部真实在用的售后工单系统。

## 1. 色彩

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--primary` | `#19324A` | 顶部栏、主按钮、当前菜单、关键数字 |
| `--secondary` | `#356A7A` | 次级按钮、筛选选中态、普通图表系列、进度条 |
| `--accent` | `#456C7E` | 链接、信息提示、图表对比系列 |
| `--bg` | `#F4F6F8` | 主内容区背景 |
| `--surface` | `#FFFFFF` | 表格、表单、卡片容器 |
| `--success` | `#2B7955` | 已完成、已通过、按期解决 |
| `--warning` | `#8A6117` | 即将超时、待补充、延时待批 |
| `--danger` | `#B02A37` | 驳回、超时、异常、删除确认（仅小面积） |
| `--text` | `#17222C` | 正文 |
| `--text-sub` | `#5B6A76` | 辅助文字、表头、说明 |
| `--line` | `#DEE4E9` | 分割线、边框 |
| `--tint` | `#EDF1F4` | 标签底色、条槽、斑马纹 |

派生图表色阶（同一含义跨页面保持一致）：

- 主系列 `#356A7A`
- 对比系列 `#456C7E`
- 浅系列 `#8AA6B2`
- 中性 `#B4C0CC`

**状态不得只靠颜色表达**，必须同时给出中文标签。标签色仅五档（gray / blue / green / amber / red），不新增第六种颜色。

## 2. 字体阶梯

系统中文优先：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`

| 层级 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| H1 | 20 / 28 | 600 | 页面标题 |
| H2 | 15 / 22 | 600 | 卡片标题 |
| H3 | 14 / 21 | 600 | 分区小标题 |
| Body | 14 / 22 | 400 | 正文 |
| Table | 13 / 20 | 400 | 表格、表单 |
| Caption | 12 / 18 | 400 | 表头、辅助说明 |
| Metric | 25 / 32 | 600 | KPI 数字 |

数字列统一 `font-variant-numeric: tabular-nums`，保证纵向对齐；编号、金额、时效、满意度均按此处理。

## 3. 圆角 / 阴影 / 间距

- 圆角：卡片 8px，按钮与输入框 6px，标签 4px，头像 50%。不使用 12px 以上大圆角。
- 阴影：**只用于抽屉与弹窗**（`-8px 0 24px rgba(23,34,44,.14)`）。卡片一律 1px 边框，不加投影。
- 间距基数 4：外边距 24，卡片内边距 16/18，区块间 14–16，控件间 8，表格单元格 9–12。

## 4. 布局框架

- 桌面端：左菜单 **220px** + 顶栏 **56px** + 自适应内容区，内容区 padding **24px**。
- 外壳 `.shell{height:100vh;overflow:hidden}`，滚动只发生在 `.content`。**这是保证 1440×900 一屏的前提**——用 `min-height:100vh` 会被长菜单撑高，整页出现滚动条。
- 表单标签 96–120px，单列输入宽 360–520px，搜索下拉宽 180–240px。
- 侧边栏菜单项 `padding:4px 18px`，行高 21px；超过 16 项时不得再加 padding，否则会撑破 900。

## 5. 角色视觉区分

同一钢蓝色系，用**侧栏底色深浅 + 品牌字**区分身份，游客端走浅色门户：

| 角色 | 侧栏底色 | 说明 |
|---|---|---|
| 客服组长 / 质量经理 | `#19324A` | 最深，主控视角 |
| 客服人员 | `#23415C` | 次深，受理视角 |
| 责任部门处理人 | `#2A4E5E` | 偏青，执行视角 |
| 系统管理员 | `#121F2E` | 近黑，配置视角 |
| 客户 | 无侧栏 | 浅色门户 `#F4F6F8` + 白卡片 |

## 6. 状态语义映射

主流程：`待受理 → 已分派 → 处理中 → 待审核 → 待客户确认 → 待回访 → 已归档`

| 状态 | 标签色 | 说明 |
|---|---|---|
| 待受理 | `t-gray` | 未进入流转 |
| 已分派 | `t-blue` | 已指派责任人 |
| 处理中 | `t-blue` | 调查/方案中 |
| 待审核 | `t-amber` | 等待组长审核 |
| 待客户确认 | `t-amber` | 等待客户反馈 |
| 待回访 | `t-amber` | 未回访不得归档 |
| 已归档 | `t-green` | 终态 |
| 已退回 / 已取消 | `t-red` | 异常终止，必须留原因 |

## 7. 图表规范

- 看板固定 **6 个 KPI + 6 个图表**，4 列网格、行高 236px，扣除页头 62px + KPI 76px 后正好落在 900 内。
- 图表内不写标题以外的文字；图例在右侧，字号 12。
- 图表可点击下钻到带相同筛选条件的列表（实现阶段挂路由）。
