# 组件规范

所有组件在 `mock.css` 中已落地类名，实现阶段 1:1 复用，不得另起一套尺寸。

## 按钮 `.btn`

| 变体 | 类名 | 用途 |
|---|---|---|
| 主按钮 | `.btn.primary` | 每屏最多 1 个（提交、分派、确认） |
| 默认 | `.btn` | 次要操作（导出、重置） |
| 浅底 | `.btn.ghost` | 筛选区、行内高频操作 |
| 危险描边 | `.btn.danger` | 驳回、作废、取消工单，必须二次确认 |
| 小号 | `.btn.sm` | 表格行内、分页 |

尺寸：默认 `padding:7px 14px / 34px 高`；小号 `3px 10px / 26px 高`。圆角 6px，边框 1px。禁用态 `opacity .5; cursor:not-allowed`。行内最多「查看 + 2 个高频操作」，其余进「更多」菜单。

## 表单

- 输入框高 **34px**，边框 `--line`，聚焦 `border-color:--secondary` + 3px 14% 透明外环。
- 表单项结构 `.fgrid .it`：标签 96px 右对齐 + 控件 flex:1。两列网格，跨列用 `.full`。
- 搜索下拉 **180–240px**（`select{width:200px}`），禁止撑满整行。
- 必填项标签前加红色 `*`；错误提示在控件下方 12px 红字。
- 关闭有未保存内容的抽屉/页面必须先弹确认。

## 表格

- 表头底色 `#F2F5F7`，字号 12，`white-space:nowrap`，**不写死列宽**，仅设最小宽度并允许横向滚动。
- 单元格 `padding:9px 12px`，下边框 `#EDF0F3`，hover 行底色 `#F8FAFB`。
- 编号、状态、日期、操作列强制单行；长文本列最多两行后省略。
- 空状态：整行居中、`padding:36px 0`，文案说明原因并给出下一步，例如「当前筛选条件下无记录，清空筛选或新建客诉工单」。

## 状态标签 `.tag`

`padding:1px 7px`，字号 12，圆角 4，五档色见设计系统第 6 节。标签内可加 6px 圆点表示严重度，但文字必须保留。

## 卡片与 KPI

- 卡片：白底 + 1px 边框 + 8px 圆角 + `16px 18px` 内边距，无阴影。标题 15px/600，右上角可放 12px 灰色说明或操作。
- KPI 卡：`label 12px 灰` + `value 25px/600 等宽数字` + `delta 12px`（正向绿、负向红）。
- 看板 KPI 使用 `.kpis.compact`（value 压到 21px），为图表腾出高度。

## 分页 `.pager`

右对齐：`共 N 条 · 每页 [10/20/50] 条` + 上一页/页码/下一页。默认每页 10 条，切换筛选后页码回到 1。服务端分页，前端只传页码与条数。

## 时间轴 `.timeline`

左侧 1px 竖线 + 9px 圆点（默认钢蓝描边、完成绿、异常红）。每条含事件标题 13px、操作人 + 时间 12px 灰。事件只读，不可编辑。

## 抽屉 `.drawer`

宽 **460px**，右侧滑出，带 `-8px 0 24px` 阴影 + `rgba(23,34,44,.26)` 遮罩。顶部固定展示单据编号、当前状态、责任人；中部表单；底部固定操作条。审批类抽屉内必须同时展示单据摘要，避免来回切页。

## 文件上传

- 尺寸 104×104 的虚线方块，hover 变实线，已上传显示缩略图 + 右上角删除。
- 显示进度条、类型限制（jpg/png/pdf，≤10MB）、删除二次确认。
- **禁止出现让用户手填图片 URL 的输入框**，一律走上传组件。

## 流程条 `.flow`

状态胶囊横排，已完成 `done`（绿底）、当前 `on`（蓝底加粗）、未到（灰底），中间用 `›` 连接。用于详情页顶部展示流转进度。

## 空/加载态

- 加载超过 300ms 显示表格骨架或卡片骨架，禁止整页白屏。
- 空列表用文案 + 一个主操作按钮，不用纯插画。
